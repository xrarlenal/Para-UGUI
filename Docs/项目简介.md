# 项目简介

个人项目，独立完成。一个第一人称射击训练场，战斗 HUD、背包、设置、武器切换四套界面全部悬浮在实时渲染的 3D 场景上，目的是验证游戏 UI 叠在动态画面上如何保持清晰，以及怎么在 UGUI 上做出真正的毛玻璃。

游戏界面平时就盖在实时画面上：半透明底色会透出杂乱背景、压不住文字，静态的模糊贴图又跟画面脱节。这里的毛玻璃在 URP 管线里逐帧生成，把不带 UI 的画面拷贝到一张与屏幕同分辨率的离屏纹理，生成 mip 链，UI 按像素自身的屏幕坐标采样高 LOD，所以面板透出的是它背后被真实模糊过的场景，模糊程度随面板层级变化。凡是要把界面叠在实时画面上的游戏，不管是射击、驾驶还是开放世界，HUD、背包、暂停菜单、设置页都能沿用这套做法。

技术栈是 Unity 2022.3.62f3c1 与 URP 14.0.12，用 C# 和 UGUI 开发。毛玻璃由自定义 ScriptableRendererFeature 与 ScriptableRenderPass 实现，RenderPass 里用 CommandBuffer 拷贝相机颜色、GenerateMips 生成 mip 链、SetGlobalTexture 把纹理交给 UI；UI Shader 是手写 HLSL，屏幕 UV 用 ComputeScreenPos 换算，tex2Dlod 按 LOD 采样；圆角贴图、准星、枪械、场景也全部由 C# 程序化生成。
